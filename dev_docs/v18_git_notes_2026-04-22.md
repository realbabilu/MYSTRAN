## 8) LINK9 memory hardening untuk model node/elemen besar

File:

- `Source/LK9/L91/WRITE_FEMAP_ELFO_VECS.f90`
- `Source/LK9/L91/WRITE_FEMAP_STRE_VECS.f90`
- `Source/LK9/L91/WRITE_FEMAP_STRN_VECS.f90`
- `Source/LK9/L91/WRITE_FEMAP_GRID_VECS.f90`

Perbaikan:

- Ubah temporary array besar berbasis `NUM_FEMAP_ROWS` / `NGRID` dari automatic local array ke `ALLOCATABLE`.
- Tambah `ALLOCATE` saat awal processing dan `DEALLOCATE` sebelum `RETURN`.

Tujuan:

- Mengurangi risiko hang/crash karena tekanan stack/heap pada kasus model besar di path LINK9/FEMAP output.
- Perilaku numerik/output tetap sama; perubahan hanya strategi memori.
