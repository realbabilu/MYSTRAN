PxzP_{xz}Pxz​ and PyzP_{yz}Pyz​ (6×6) take the xzxzxz or yzyzyz shear component of RTεRR^T\varepsilon RRTεR and rotate it back. The tied operator is

3.6 Correction

Let ΔB=B~−B\Delta B=\tilde B-BΔB=B~−B. Affine and patch consistency require

  • (C1) B~uaff=ε0\tilde B\mathbf u_{\rm aff}=\varepsilon_0B~uaff​=ε0​: constant strain is reproduced;
  • (C2) ∑gwgB~g=∑gwgBg\sum_g w_g\tilde B_g=\sum_g w_gB_g∑g​wg​B~g​=∑g​wg​Bg​: equilibrium for constant stress.

Tied-EAS9 satisfies C1 pointwise (single frame RRR) but not C2 on distorted elements. The correction

B~′=B~−∑gwgΔBg∑gwg\tilde B'=\tilde B-\frac{\sum_g w_g\Delta B_g}{\sum_g w_g}B~′=B~−∑g​wg​∑g​wg​ΔBg​​

enforces C2 exactly and keeps C1, since ΔBguaff=0\Delta B_g\mathbf u_{\rm aff}=0ΔBg​uaff​=0 at every point. On parallelepipeds the mean of ΔB\Delta BΔB is zero and the correction vanishes.

3.7 Auto axis

The mean edge length along ξ\xiξ, η\etaη, ζ\zetaζ is computed; the shortest direction becomes ζ\zetaζ by a cyclic relabelling of the natural axes (handedness preserved). The EAS9 mode set is invariant under cyclic permutation. KKK is computed on the permuted node order and mapped back.

4. Solution steps

Element

  1. Read node coordinates XXX (8×3), EEE, ν\nuν; form DDD.
  2. Compute J0J_0J0​, det⁡J0>0\det J_0>0detJ0​>0. Versions 3–7: form T0T_0T0​. Version 7: find the shortest direction and permute nodes.
  3. Versions 5–7: form RRR, PxzP_{xz}Pxz​, PyzP_{yz}Pyz​.
  4. At each of the 8 Gauss points: compute JJJ, det⁡J>0\det J>0detJ>0, ∇N\nabla N∇N, BBB. Versions 5–7: also B(0,η,ζ)B(0,\eta,\zeta)B(0,η,ζ), B(ξ,0,ζ)B(\xi,0,\zeta)B(ξ,0,ζ), then B~\tilde BB~ and ΔB\Delta BΔB. Versions 2–7: MMM.
  5. Version 6–7: subtract the weighted mean of ΔB\Delta BΔB from B~\tilde BB~.
  6. Accumulate KuuK_{uu}Kuu​, KuαK_{u\alpha}Kuα​, KααK_{\alpha\alpha}Kαα​ with weight det⁡J\det JdetJ (using B~′\tilde B'B~′ in versions 5–7).
  7. Condense: K=Kuu−KuαKαα−1KuαTK=K_{uu}-K_{u\alpha}K_{\alpha\alpha}^{-1}K_{u\alpha}^TK=Kuu​−Kuα​Kαα−1​KuαT​, symmetrise; version 7: map back to the original node order.

Global

  1. Assemble element matrices into a sparse global KKK (3 DOF per node).
  2. Partition free and constrained DOF; build the load vector.
  3. Solve Kffuf=FfK_{ff}\mathbf u_f=F_fKff​uf​=Ff​ with sparse LU.
  4. Average the displacement over the probe nodes and compare with the reference.
