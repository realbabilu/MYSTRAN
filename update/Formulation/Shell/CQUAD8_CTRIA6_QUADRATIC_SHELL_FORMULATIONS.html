Abstract

This manuscript documents the mathematical basis and bounded validation evidence of five eight-node serendipity quadrilateral and four six-node quadratic triangular shell formulations for MYSTRAN. It distinguishes original published mechanics from research adaptations, including assumed-strain projections, drilling stabilization, pointwise tensor recovery, and linearized initial-stress stiffness. Equations, shape functions, quadrature and tying diagrams are accompanied by independent verification tables whose unavailable numerical fields remain blank. Element selection is conditional on analysis class; no overall ranking is assigned.

1. Scope and conventions

This document describes finite-element formulations, not the programming interface. A named element identifies a reproducible mathematical model rather than a software class. All elements use \(\mathbf q_I=(u_x,u_y,u_z,\theta_x,\theta_y,\theta_z)_I\). Local stress/resultant components are compared only after applying the appropriate tensor transformation. CW and CCW windings are both admissible when the geometric mapping is regular and the normal orientation is used consistently. Most material and buckling evidence is for isotropic small-strain shell response; it does not imply the complete finite-rotation nonlinear theory of the cited papers.

2. Coordinates, kinematics and global DOFs

2.1 Geometry and winding

For an isoparametric midsurface with natural coordinates \((r,s)\), \[ \mathbf x(r,s)=\sum_{I=1}^{n}N_I(r,s)\mathbf x_I,\quad \mathbf g_r=\frac{\partial\mathbf x}{\partial r},\quad \mathbf g_s=\frac{\partial\mathbf x}{\partial s},\quad J_A=\|\mathbf g_r\times\mathbf g_s\|,\quad \mathbf n=\frac{\mathbf g_r\times\mathbf g_s}{J_A}. \]

Winding controls the oriented normal and, consequently, sign of oriented pressures and local bending/shear results. A CW element is not invalid merely because it is CW; an implementation may support both if mapping and sign conventions are consistent. The current DUEL3A CW deck is retained as a reference, while DUEL3B isolates quadratic elements. Use the oriented normal; do not force +Z on general curved geometry. For planar XY audit use \(J_{xy}=x_{,r}y_{,s}-x_{,s}y_{,r}\): positive implies CCW relative to global +Z.

2.2 Displacements and rotations

Each node has \(\mathbf q_I=[u_I,v_I,w_I,\theta_{xI},\theta_{yI},\theta_{zI}]^{T}\), resulting in \(48\times48\) (Q8) or \(36\times36\) (T6) stiffness. Let \(\mathbf t_1,\mathbf t_2,\mathbf n\) be orthonormal local directions. In a linear Reissner–Mindlin approximation, \[ \mathbf u(r,s,z)=\mathbf u_0(r,s)+z(\boldsymbol\theta(r,s)\times\mathbf n),\qquad \mathbf u_0=\sum_I N_I\mathbf u_I,\quad \boldsymbol\theta=\sum_I N_I\boldsymbol\theta_I. \] The original degenerated-director derivations of some references have five physical DOFs, with no drilling variable. The Python/MYSTRAN compatibility layer introduces a sixth nodal rotation and a separate drilling constraint: that is an adaptation, not an identity with the reference paper. In curved shell implementations director normals may vary node-to-node, so the above expression is a reference linearization rather than a complete description of each Python class.

2.3 Local physical membrane, curvature, shear operators

Using \(x,y\) as coordinates along the local tangent plane and the convention \(\boldsymbol\theta\times\mathbf n=(\theta_y,-\theta_x,0)\) for \(\mathbf n=\hat z\), \[ \boldsymbol\varepsilon_m=\begin{bmatrix}u_{,x}\\v_{,y}\\u_{,y}+v_{,x}\end{bmatrix}=B_m\mathbf q,\qquad \boldsymbol\kappa=\begin{bmatrix}\theta_{y,x}\\-\theta_{x,y}\\\theta_{y,y}-\theta_{x,x}\end{bmatrix}=B_b\mathbf q, \] \[ \boldsymbol\gamma=\begin{bmatrix}w_{,x}+\theta_y\\w_{,y}-\theta_x\end{bmatrix}=B_s\mathbf q. \] For a standard interpolation with physical derivatives \(N_{I,x},N_{I,y}\), the illustrative 3×6 nodal blocks are \[ B_m^I=\begin{bmatrix}N_{I,x}&0&0&0&0&0\\0&N_{I,y}&0&0&0&0\\N_{I,y}&N_{I,x}&0&0&0&0\end{bmatrix}, \quad B_b^I=\begin{bmatrix}0&0&0&0&N_{I,x}&0\\0&0&0&-N_{I,y}&0&0\\0&0&0&-N_{I,x}&N_{I,y}&0\end{bmatrix}, \] \[ B_s^I=\begin{bmatrix}0&0&N_{I,x}&0&N_I&0\\0&0&N_{I,y}&-N_I&0&0\end{bmatrix}. \] Crucial: these are baseline operators. MITC8, ANS8, MITC6, Rezaiee, MacNeal variants replace or reproject specified rows. Do not equate all their \(B\) matrices with these direct-gradient blocks.

2.4 Drilling rotation and objective rigid motion

A common 6-DOF adaptation ties \(\theta_z\) to in-plane skew displacement gradient: \[ \gamma_d=\theta_z-\tfrac12(v_{,x}-u_{,y})=B_d\mathbf q, \qquad K_d=\int_A \alpha_d B_d^TB_d\,\mathrm dA. \] Define \(\alpha_d\) explicitly per class (it may scale with \(Gh\), \(G\), \(\beta_{drill}\), \(k_t\)). Sign conventions can differ; energy-equivalent \(B_d\) signs are harmless only when the entire row is reversed. A penalty fixed in absolute units may corrupt thin-shell convergence. Verify rigid rotation \(\mathbf u=\boldsymbol\omega\times\mathbf x\) and \(\boldsymbol\theta=\boldsymbol\omega\), and test \(\mathbf q_{RBM}^{T}K\mathbf q_{RBM}\to0\).

2.5 Constitutive blocks, thickness and units

For homogeneous isotropic material, \[ D_p=\frac{E}{1-\nu^2}\begin{bmatrix}1&\nu&0\\\nu&1&0\\0&0&(1-\nu)/2\end{bmatrix},\quad D_s=\kappa_s G I_2,\quad G=\frac{E}{2(1+\nu)}. \] \[ A=hD_p,\qquad D=\frac{h^3}{12}D_p,\qquad S=hD_s,\qquad K_e=\int_A(B_m^TAB_m+B_b^TDB_b+B_s^TSB_s+\alpha_d B_d^TB_d)\,\mathrm dA. \] For a general laminate or eccentric reference surface use \(\begin{bmatrix}N\\M\end{bmatrix}=\begin{bmatrix}A&B\\B&D\end{bmatrix}\begin{bmatrix}\varepsilon_m\\\kappa\end{bmatrix}\), where \(A=\int C(z)dz\), \(B=\int zC(z)dz\), \(D=\int z^2C(z)dz\). The documented baseline implementations mainly assume constant isotropic thickness; introducing a generic ABD expression here does not mean composite ABD has been implemented.

3. Shape functions: independent Q8 and T6 definitions

3.1 Eight-node serendipity Q8

Corner natural coordinates \((r_I,s_I)=(-1,-1),(1,-1),(1,1),(-1,1)\). For \(I=1,\ldots,4\): \[ N_I=\frac14(1+r_Ir)(1+s_Is)(r_Ir+s_Is-1). \] For midside nodes in the numbering illustrated above: \[ \begin{aligned} N_5&=\tfrac12(1-r^2)(1-s),&N_6&=\tfrac12(1+r)(1-s^2),\\ N_7&=\tfrac12(1-r^2)(1+s),&N_8&=\tfrac12(1-r)(1-s^2). \end{aligned} \] Differentiation must be analytical (or independently checked using complex-step / numerical derivatives). For example, \(N_{5,r}=-r(1-s)\), \(N_{5,s}=-(1-r^2)/2\). The 2×2 physical map for planar geometry is \(J=[\mathbf x_{,r}^{T};\mathbf x_{,s}^{T}]\); hence \([N_{,x};N_{,y}]=J^{-1}[N_{,r};N_{,s}]\). For true curved surfaces, use surface tangent/dual basis rather than a frozen two-dimensional map for geometry-sensitive operators.

3.2 Six-node quadratic triangle T6

Barycentric coordinates \(L_1=1-r-s,L_2=r,L_3=s\), with \(r\ge0,s\ge0,r+s\le1\): \[ \begin{aligned} N_1&=L_1(2L_1-1),&N_2&=L_2(2L_2-1),&N_3&=L_3(2L_3-1),\\ N_4&=4L_1L_2,&N_5&=4L_2L_3,&N_6&=4L_3L_1. \end{aligned} \] Examples: \(N_{1,r}=1-4L_1\), \(N_{4,r}=4(L_1-L_2)\), \(N_{6,s}=4(L_1-L_3)\). The reference triangle has area \(1/2\), not 1; quadrature weights must integrate constants to \(1/2\). T6 is not a 3-node triangle with only midside geometry: all six translational/rotational nodal fields participate.

3.3 Curvilinear strain transformation

With covariant tangents \(g_\alpha=\partial x/\partial\xi^\alpha\) and dual basis \(g^\alpha\), natural linear membrane strains are \[ \varepsilon_{\alpha\beta}=\frac12\sum_I\left[(g_\alpha\cdot\mathbf u_I)N_{I,\beta}+(g_\beta\cdot\mathbf u_I)N_{I,\alpha}\right]. \] The physical tensor is \(\boldsymbol\varepsilon=\varepsilon_{\alpha\beta}\,\mathbf g^\alpha\otimes\mathbf g^\beta\), expressed in an orthonormal physical basis before multiplying the isotropic constitutive matrix. Do not directly average covariant components from different tangent bases. This is central to Jung-inspired and curved MITC operator audits.

4. Gauss quadrature and tying diagrams

For Q8 standard 3×3 Gauss–Legendre quadrature in \([-1,1]^2\): abscissae \(\{-b,0,+b\}\), \(b=\sqrt{3/5}\), one-dimensional weights \(\{5/9,8/9,5/9\}\). Integrate as \[ K_e\approx\sum_{i=1}^3\sum_{j=1}^3 w_iw_j\,J_A(r_i,s_j)\,\mathcal B(r_i,s_j). \] For T6, a Duffy map of \([0,1]^2\) can be used: \(r=a,s=(1-a)b\), \(\mathrm dr\mathrm ds=(1-a)\mathrm da\mathrm db\); if transformed from \([-1,1]^2\), both factors \(1/2\) must be applied correctly. Alternative exact symmetric triangle quadrature is acceptable if it integrates the target polynomial degree and geometric variation accurately.

Tying points are not Gauss integration points. Interpolation samples are selected to construct assumed \(\bar B_m\) or \(\bar B_s\), then the resulting energy is integrated at quadrature points. A formula such as \[ \bar B_\alpha(r,s)=\sum_{k=1}^{n_t}L_k^{(\alpha)}(r,s)\,B_\alpha(r_k,s_k) \] requires explicit sample coordinates, interpolation weights, covariant/physical transformation and row ordering. The number and location \(n_t\) differ by element and by operator. A 6-point shear fit does not automatically pass a distorted patch test; do not swap it into a published element without revalidation.

5. General element construction: reproducible algorithm

  1. Read node coordinates (Q8 eight, T6 six), material \(E,\nu,\rho,h\), element options and requested coordinate systems; check node/edge mapping and nondegeneracy.
  2. Construct nominal frame and—when the formulation uses them—nodal directors and Gauss-point tangent bases; enforce consistent handedness, not a global +Z shortcut.
  3. Evaluate geometric standard \(N^g,dN^g\) at Gauss points. Distinguish geometry interpolation from modified displacement/strain fields \(N^f,dN^f\).
  4. Build direct physical strain rows and/or natural covariant rows; evaluate tying-point rows, interpolate assumed strains, transform consistently to physical frame.
  5. Build \(B_m,B_b,B_s,B_d\), integration weight \(w_qJ_A\); assemble material and drilling parts independently so each energy contribution can be audited.
  6. Construct 6n×6n transformation \(T=\mathrm{blockdiag}(R^T,R^T,\ldots)\) for fixed-frame elements. Verify \(K_g=T^TK_lT\) and the code's actual vector convention; some global-coordinate formulations use \(T=I\).
  7. Independently assemble equivalent nodal pressure/traction forces, thermal eigenstrains and mass; do not reuse modified shape fields as geometric Jacobians unless that is a deliberate, documented choice.
  8. Check symmetry, six null eigenvectors, positivity on the constrained subspace, finite conditioning, rigid-body invariance, patch consistency and load resultant/first moment.
  9. Solve, recover resultants and stresses at documented locations in documented axes, and export source-identified CSV rows. Record solver failures rather than silently skipping negative-Jacobian integration points.

6. Mass, thermal, pressure and initial-stress buckling

6.1 Mass

With \(\mathbf N_u=[N_1I_3\ \cdots\ N_nI_3]\), consistent translational mass is \[ M_{uu}=\rho h\int_A\mathbf N_u^T\mathbf N_u\,dA,\qquad M_{rr}=\rho h^3/12\int_A\mathbf N_r^T\mathbf N_r\,dA \] for available rotary inertia channels. Drilling rotary inertia is frequently zero. Row-sum lumping of Q8 shape-function mass matrices may create unacceptable or zero/negative nodal masses; check total mass, positive diagonal and modal stability, not just mass sum. Eigen regularization is not independent evidence that every the corresponding mathematical operator works.

6.2 Thermal eigenstrain and consistent load

With linear through-thickness temperature \(\Delta T(z)=\Delta T_0+z\Delta T_1\) and isotropic expansion \(\alpha\): \[ \varepsilon_T(z)=\alpha\Delta T(z)[1,1,0]^T,\quad N_T=\int_{-h/2}^{h/2}D_p\varepsilon_T(z)\,dz= hD_p\alpha\Delta T_0[1,1,0]^T, \] \[ M_T=\int_{-h/2}^{h/2}zD_p\varepsilon_T(z)\,dz=\frac{h^3}{12}D_p\alpha\Delta T_1[1,1,0]^T, \quad f_T=\int_A(B_m^TN_T+B_b^TM_T)\,dA. \] If input instead supplies top-minus-bottom \(\Delta T_{tb}\), then \(\Delta T_1=\Delta T_{tb}/h\). This distinction prevents a hidden factor of thickness in thermal comparisons. Thermal resultants must be subtracted in stress recovery: \(N=A\varepsilon_m-N_T\), \(M=D\kappa-M_T\).

6.3 Pressure and work conjugacy

For pressure \(p\) in oriented normal direction, consistent nodal load is \[ \mathbf f_p=\int_{\Omega_{nat}}\mathbf N_u^{T}\,p(r,s)[\mathbf g_r\times\mathbf g_s] \,dr\,ds. \] For a specified global traction direction \(\hat{\mathbf d}\), replace the oriented vector by \(J_A\hat{\mathbf d}\). In both cases check \(\sum_I\mathbf f_I=\int_A\mathbf t\,dA\), \(\sum_I\mathbf x_I\times\mathbf f_I=\int_A\mathbf x\times\mathbf t\,dA\). CW normal-pressure sign reverses relative to CCW; prescribed global force direction must not reverse automatically.

6.4 Initial-stress stiffness: documented restricted scope

For a flat, prestressed surface with tension-positive local membrane Cauchy stress \(S=[\sigma_{11},\sigma_{22},\tau_{12}]\), a translational initial-stress operator is \[ K_G^{(ab)}=h\int_A \nabla N_a^T\begin{bmatrix}\sigma_{11}&\tau_{12}\\\tau_{12}&\sigma_{22}\end{bmatrix}\nabla N_b\,dA\ I_3. \] This integrates membrane Cauchy stress, not force resultants; multiplying resultant \(N=hS\) by thickness again is wrong. The buckling eigenproblem is \((K+\lambda K_G)\phi=0\), with compressive stress giving negative energy directions and positive critical \(\lambda\). Compute \(\|K\phi+\lambda K_G\phi\|/(\|K\phi\|+|\lambda|\|K_G\phi\|)\), confirm mode-shape physics and load normalization.

The uploaded the corresponding mathematical operator explicitly rejects curved/warped geometry and excludes director/rotation stress terms, nonlinear prebuckling and follower loads. Thus none of our historical 2-016/2-017 results certify full nonlinear curved-shell tangents. This restriction must be disclosed even if the underlying journal references include nonlinear shell derivations.

7. Nine independent formulations

7.1 SIMOQ8 v13 — eight-node serendipity shell

The surface uses the Q8 serendipity functions of §3.1. Nodal directors \(\mathbf d_I\) define the rotation-induced through-thickness displacement \(\mathbf u(z)=\sum_I N_I[\mathbf u_I+z(\boldsymbol\theta_I\times\mathbf d_I)]\). The physical strain operators follow the covariant surface map \(\mathbf g_\alpha=\mathbf x_{,\alpha}\), with tensor transformation to an orthonormal tangent frame. The material stiffness is \[ K^{\mathrm{SIMOQ8}}=\int_A\!\left[h\bar B_m^TC_m\bar B_m+\frac{h^3}{12}B_b^TC_mB_b+h\bar B_s^TC_s\bar B_s+h\,c_dB_d^TB_d\right]dA. \] An optional assumed-strain branch replaces directly computed membrane or shear strain rows by projected rows \(\bar B_\alpha=\sum_j L_j^{(\alpha)} B_\alpha(\xi_j)\), whereas bending and drilling are treated separately. An optional incompatible/enhanced strain contributes an internal field \(\varepsilon^{E}=G\alpha\), with the condensed stiffness \(K_{qq}^{\star}=K_{qq}-K_{q\alpha}K_{\alpha\alpha}^{-1}K_{\alpha q}\) only when that branch is active and nonsingular. This is not a claim that the entire nonlinear Simo–Fox–Rifai algorithm is reproduced. Adopted: director kinematics, stress-resultant decomposition, local covariance. Modified: Q8 shape basis, conditional assumed/enhanced strains and drilling penalty. Not reproduced: full geometrically exact time integration, finite rotational tangent, large-strain plasticity and thickness stretching.

7.2 SIMOT6 v2 — six-node triangular shell

Using the P2 triangle basis \(N_I(L_1,L_2,L_3)\) of §3.2 and \(\Omega_\triangle=\{r\ge0,s\ge0,r+s\le1\}\), construct directors independently for six nodes and the covariant surface gradient \(\mathbf g_r,\mathbf g_s\). The strain–rotation operators are evaluated in the moving physical tangent basis and the triangular stiffness is \[ K^{\mathrm{SIMOT6}}=\int_{\Omega_\triangle}\left[hB_m^TC_mB_m+\frac{h^3}{12}B_b^TC_mB_b+hB_s^TC_sB_s+h c_dB_d^TB_d\right]J_A\,dr\,ds. \] Where projected rows are selected, they must use a triangular polynomial space and triangle sample positions; Q8 tensor-product tying is not transferable. Adopted: stress-resultant director theory and objective frame requirements. Modified: P2 triangle interpolation, six-DOF representation and drilling constraint. Not reproduced: exact finite-rotation geometric Simo tangent. SIMOT6 is an independent formulation, not a corner-reduced SIMOQ8.

7.3 MITC8 v4 — mixed covariant tensorial interpolation

The covariant in-layer strain is \(\varepsilon_{\alpha\beta}=\tfrac12(\mathbf g_\alpha\cdot\mathbf u_{,\beta}+\mathbf g_\beta\cdot\mathbf u_{,\alpha})\), with separate assumed membrane and transverse shear tensors. Curved surfaces use a metric-aware conversion into physical components rather than treating covariant strains as Cartesian strains. For membrane normal rows, define \(b=\sqrt{3/5}\), \(P_\pm(x)=(1\pm x)/2\), and \(Q_j(x)\), the quadratic cardinal functions at \((-b,0,b)\). Then \[ \bar\varepsilon_{rr}(r,s)=\sum_{i\in\{-1,1\}}\sum_{j\in\{-b,0,b\}}P_i(r)Q_j(s)\varepsilon_{rr}(i,j),\quad \bar\varepsilon_{ss}(r,s)=\sum_{i\in\{-1,1\}}\sum_{j\in\{-b,0,b\}}Q_j(r)P_i(s)\varepsilon_{ss}(j,i). \] For \(a=1/\sqrt3\), the mixed in-plane shear is \(\bar\varepsilon_{rs}=\sum_{i,j\in\{-a,a\}}L_i(r)L_j(s)\varepsilon_{rs}(i,j)\), with \(L_{\pm a}(x)=(a\pm x)/(2a)\). This membrane tying is activated on curved/warped geometry and otherwise the direct membrane interpolation is retained. The transverse shear operator is given by §8. Drilling stabilization and optional locally modified displacement fields are research adaptations. Adopted: MITC covariant component interpolation and physical strain transformation (Bathe–Dvorkin; Dvorkin). Modified: curvature-conditioned membrane tying, the slenderness-dependent shear blend and six-DOF drilling. Not reproduced: original five-DOF complete nonlinear tangent and unmodified historical MITC8 operators.

7.4 ANS8BDG6 v4 — enhanced ANS quadrilateral

The normal-strain components employ two longitudinal sides and three points per side (six per component). Thus \(\bar\varepsilon_{rr}\) and \(\bar\varepsilon_{ss}\) use the \(P_iQ_j\) interpolation above, while in-plane shear uses four \((\pm1/\sqrt3,\pm1/\sqrt3)\) samples and bilinear reconstruction. Curvature and midside deviation determine whether the membrane projection is active; a flat straight-sided element retains direct membrane strains. Transverse shear uses the alternative four- and six-point fields of §8.

The drilling variable is weakly constrained by the physical in-plane spin: \[ \Pi_d=\frac12\int_A k_tGh\left(\theta_n-\tfrac12(v_{,x}-u_{,y})\right)^2dA,\quad k_t=0.1\ \text{(selected reference parameter)}. \] Adopted: β/δ sampling philosophy and enhanced transverse shear collocation from Jung–Han (2013), plus the drilling-spin energy idea. Modified: modified-field shape interpolation, conditional membrane tying, blended shear and six-DOF small-strain implementation. Not reproduced: a proven exact implementation of the paper's full \(\beta\delta\gamma^*_6\) interpolation or its nonlinear solution history.

7.5 HBQ8 Kikuchi v3 — modified-field hybrid quadrilateral

The adopted field interpolation \(\widetilde N_I(r,s;\mathbf x)\) is geometry-sensitive (Kikuchi-type variant), giving physical surface gradients \(\nabla_\Gamma\widetilde N_I\); however surface area is integrated from the standard Q8 geometric map. Membrane, bending and drilling energies are evaluated from separate differential rows, with the selected shear assumed field from §8. Its total stiffness retains the four mechanical energies of §5 and the drilling energy of §7.4, with its own drilling coefficient. The geometry switch is \[ \chi_c=\begin{cases}1,&\theta_{\max}>0.01\ \mathrm{rad}\quad\text{or}\quad\delta_{mid}>10^{-3},\\0,&\text{otherwise},\end{cases} \quad\delta_{mid}=\max_e\frac{\left\|\mathbf x_{m_e}-\tfrac12(\mathbf x_{a_e}+\mathbf x_{b_e})\right\|}{\|\mathbf x_{b_e}-\mathbf x_{a_e}\|}. \] Here \(\theta_{\max}=\max_I\arccos(\mathbf d_I\cdot\bar{\mathbf d})\) with normalized average director \(\bar{\mathbf d}\). For \(\chi_c=0\), direct membrane field; for \(\chi_c=1\), covariantly tied membrane field. This is a formulation criterion, not a programming routine. Adopted: HBQ8 shell-energy decomposition and Kikuchi-type modified interpolation. Modified: switching and shear blending. Not reproduced: full geometrically nonlinear shell tangent.

7.6 MacNeal Q8 v3 — eight-node modified interpolation with drilling

A geometry-dependent interpolation \(\widetilde N_I\) replaces the standard Q8 field for the displacement/strain approximation while preserving the eight external nodes. The surface geometry is still reconstructed from the physical Q8 nodal positions. From the modified interpolation form \(\widetilde B_m,\widetilde B_b,\widetilde B_s\) and independent drilling penalty \(\widetilde B_d\), assemble \[ K^{\mathrm{MN8}}=\int_A h\widetilde B_m^TC_m\widetilde B_m+\frac{h^3}{12}\widetilde B_b^TC_m\widetilde B_b+h\widetilde B_s^TC_s\widetilde B_s+h c_d\widetilde B_d^T\widetilde B_d\,dA. \] Adopted: MacNeal–Harder (1992) motivation for improved eight-node field interpolation. Modified: separate drilling constraint and six-DOF shell extension. Not reproduced: claim of equivalence to all original nine-node formulations or general nonlinear constitutive theory.

7.7 MITC6 v5e — enhanced six-node triangular mixed element

On the reference triangle, form the covariant membrane matrix \(B^n_m(r,s)\), and covariant transverse shear matrix \(B^n_s(r,s)\). A projection of a sampled scalar strain row \(b\) to an affine field is determined from \(\mathbf p=(1,r,s)^T\): \[ \mathbf A_{j,:}=[1,r_j,s_j],\qquad \mathbf C=(A^TWA)^{-1}A^TW\begin{bmatrix}b(r_1,s_1)\\\vdots\\b(r_m,s_m)\end{bmatrix},\qquad \bar b(r,s)=\mathbf p^T\mathbf C. \] The enhanced tying configuration changes selected internal sampling locations relative to the preceding research version; the operator must be checked on the triangle itself and cannot be inferred from a quadrilateral MITC rule. Compute physical membrane and transverse shear tensors using the surface metric; bending and drilling are separately integrated. Adopted: Kim–Bathe triangular MITC motivation and strain tying. Modified: affine reconstruction, particular tying positions and six-DOF drilling. Not reproduced: a claim that the research v5e sample selection was published unchanged in Kim–Bathe (2009).

7.8 MH6T v4 — triangular modified-field MacNeal family

Using P2 geometry, form direct bending from interpolated rotations and reconstruct in-layer/shear strains by a weighted projection over separately specified triangular sample points: \[ \bar B_\alpha(r,s)=\sum_{j=1}^{m}H_j(r,s)B^{n}_\alpha(r_j,s_j),\qquad K=\int_{\Omega_\triangle}(h\bar B_m^TC_m\bar B_m+\tfrac{h^3}{12}B_b^TC_mB_b+h\bar B_s^TC_s\bar B_s+h c_dB_d^TB_d)J_A\,dr\,ds. \] Adopted: modified/assumed-strain treatment of thin-shell locking. Modified: triangular tying and six-DOF drilling. Not reproduced: equivalence of this research interpolation to any single unmodified published MH6T element.

7.9 Rezaiee T6 v3 — modified assumed-strain triangular shell

The independent T6 shell uses six quadratic interpolation nodes and nodal director kinematics. The natural membrane and transverse shear rows are evaluated at collocation points and projected to polynomial assumed fields \(\bar\varepsilon_m=\mathcal P_m\varepsilon_m\), \(\bar\gamma=\mathcal P_s\gamma\); the physical tensor conversion employs \(\mathbf g^\alpha\), the dual tangent vectors. Its weak-form contributions are integrated on the triangle, with separate drilling stabilization. Adopted: Rezaiee–Pajand triangular assumed-strain and director concepts. Modified: linear six-DOF version and drilling. Not reproduced: original five-DOF finite-rotation nonlinear formulation and consistent nonlinear tangent.

8. Explicit shear interpolation: BDG4, tensor6 and direct

Let \(a=1/\sqrt3\), \(b=\sqrt{3/5}\), and \(\gamma_{rt},\gamma_{st}\) denote covariant transverse shear strains. Define \[ L_-(x)=\frac{a-x}{2a},\quad L_+(x)=\frac{a+x}{2a},\qquad H_-(x)=\frac{1-x}{2},\quad H_+(x)=\frac{1+x}{2}, \] \[ Q_{-b}(x)=\frac{x(x-b)}{2b^2},\qquad Q_0(x)=1-\frac{x^2}{b^2},\qquad Q_{+b}(x)=\frac{x(x+b)}{2b^2}. \]

BDG4 (four-point transverse-shear tying per component) samples \(\gamma_{rt}\) at \((r_i,s_j)=(\pm a,\pm1)\) and \(\gamma_{st}\) at \((\pm1,\pm a)\): \[ \bar\gamma_{rt}^{(4)}(r,s)=\sum_{i=\pm}\sum_{j=\pm}L_i(r)H_j(s)\gamma_{rt}(r_i,s_j),\quad \bar\gamma_{st}^{(4)}(r,s)=\sum_{i=\pm}\sum_{j=\pm}H_i(r)L_j(s)\gamma_{st}(r_i,s_j). \]

Tensor6 (six-point transverse-shear tying per component) instead uses 2×3 samples: \[ \bar\gamma_{rt}^{(6)}(r,s)=\sum_{i=\pm}\sum_{j\in\{-b,0,b\}}L_i(r)Q_j(s)\gamma_{rt}(r_i,s_j),\quad \bar\gamma_{st}^{(6)}(r,s)=\sum_{i\in\{-b,0,b\}}\sum_{j=\pm}Q_i(r)L_j(s)\gamma_{st}(r_i,s_j). \]

Direct shear means no tying projection, \(\bar\gamma_{rt}^{(d)}(r,s)=\gamma_{rt}(r,s)\), \(\bar\gamma_{st}^{(d)}(r,s)=\gamma_{st}(r,s)\). Each covariant component is converted to a physical tangent shear vector via the inverse surface metric. These options do not mean that a six-point Gauss integration rule is used: collocation and quadrature play different roles.

For the selected automatic shear treatment define slenderness \(s_A=\sqrt A/h\), transition \(s_0=15\) and mixing coefficient \[ \omega=\operatorname{clip}\left(1-\frac{s_0}{s_A},0,1\right),\quad \bar B_s=(1-\omega)\bar B_s^{(6)}+\omega\bar B_s^{(4)}. \] The operator is blended before the quadratic strain energy \(K_s=h\int\bar B_s^TC_s\bar B_s\,dA\). Consequently \(K_s\ne(1-\omega)K_s^{(6)}+\omega K_s^{(4)}\) in general. For \(s_A\le15\), tensor6 dominates; as \(s_A\rightarrow\infty\), BDG4 dominates. The name “BDG6” denotes this research ANS8 family, not proof that every selected shear interpolation employs six samples.

10.2 Comparison interpretation

The selected winding (CW or CCW), reference axis and loading definition must be recorded with the table at the time the result is inserted. A sign difference in local moments or transverse shear is not an error percentage until all components are transformed into a common physical basis. Nastran OP2 or Codex-derived CSV may populate the table once element IDs, node IDs, units, output station and solver subcases are matched. The 2-001 published independent values are \(\sigma_{xx}=\sigma_{yy}=1333\,\mathrm{psi}\), \(\tau_{xy}=400\,\mathrm{psi}\), \(M_{xx}=M_{yy}=1.111\times10^{-7}\) and \(M_{xy}=3.333\times10^{-8}\,\mathrm{lb\,in/in}\), for the official model's respective membrane and bending cases; they must not be copied blindly into the distinct DUEL3B mesh or a formulation row before load and units are matched.

11. Validation status and case-dependent element guidance (18 October 2026)

The validation deliveries are evidence, not a universal element ranking. Q8 production contains 91 thick physical models and 455 successful MYSTRAN runs across five formulations; executable coverage is 15/16 eligible benchmark IDs (2-015 pending). T6 production contains 70 thick physical models across 11 benchmark IDs and four formulations. These counts indicate execution/availability, not numerical accuracy or full CSI verification. Both campaigns use independently matched Nastran/MYSTRAN output only when physical model, observable, sampling location, and coordinate frame are consistent. Curved-shell force/stress frame comparison remains pending for many rows.

For 2-001, all four T6 formulations pass analytical flat membrane, bending and zero-transverse-shear patch checks at supported sampling locations. The repaired SIMOQ8 pointwise membrane/moment recovery also passes the flat analytical checks, but SIMOQ8 still exhibits nonuniform midside transverse shear in LC2 (reported approximately \(Q_y=0.02666667\) at GRID 510/EID 24). Do not claim complete patch-test success based on displacement or moment alone. The Q8 Nastran LC2 bending-resultant discrepancy relative to the analytical reference remains unresolved; compare actual basic-coordinate tensors and thickness/fiber conventions before interpreting it as element failure.

Analysis condition Conditional formulation guidance Validation restriction
Flat membrane or bending patch Any Q8/T6 formulation may be considered only after its own same-frame force/moment patch checks pass. T6 candidates have documented flat patch passes. SIMOQ8 midside transverse-shear LC2 still fails uniformity.
Thin plate in bending Examine SIMOQ8, MITC8, ANS8BDG6, HBQ8, MacNeal Q8 for locking and distortion sensitivity; triangulated meshes may examine MITC6/SIMOT6. No general best element follows from one plate case; confirm convergence and moment recovery.
Thick plate/shell Favor elements with verified active transverse-shear stiffness and sample-point recovery, including MITC/ANS variants as research candidates. MID3 activation, thickness, shear factor, and solver conventions must match.
Curved cylindrical or spherical shell Compare MITC8/ANS8BDG6 and triangular MITC6/SIMOT6 with curved-frame-aware processing, alongside other candidates for sensitivity. Basic-coordinate displacement may be compared now; element stress/resultant agreement is still frame-QA-pending.
Distorted or twisted shell Test each modified-field formulation on the same physical distorted mesh and compare convergence, rigid-body objectivity, and recovery. Recommendations are exploratory until same-frame, same-load benchmarks are verified.
Linear modal analysis Use any candidate with an independently validated mass model and mode matching by MAC. 2-008 production uses diagonal CONM2 only; low-MAC pairings must be withheld.
Linear eigen buckling Use elements whose prestress, geometric stiffness and eigenmode match have been audited at the selected thickness. Linearized buckling only; 2-016 thin Nastran cases have unresolved solver failures and T6 pivot recoveries require qualification.

11.1 Reproducible reporting and release criteria

Report the physical model and thickness before reporting numerical agreement. For every measured observable provide problem ID, element family and formulation, thin/thick flag, winding, independent reference (if verified), solver, point and fiber, local/basic-coordinate convention, results, difference/error and source checksum. Preserve analytical zero targets using absolute error rather than division by zero. No missing result shall be represented by numerical zero. For public repository delivery, keep source and generated benchmark DAT traceable separately and store bulky OP2/F06 outside the documentation ZIP.

The CODEx handoff included with this document assigns all DAT selection, thin/thick MID3 verification, Q8/T6 extraction, winding CCW normalization and DAT ZIP construction to Codex. The Markdown/HTML package itself contains no benchmark DAT.
