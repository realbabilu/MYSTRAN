# DSG3 transverse geometric stiffness: production with known failure

24 October 2026. User explicitly accepted this element correction for production temporarily, with the six-mode bending mode2 residual rejection recorded as a known failure. This is not a claim that all buckling runs pass.

## Default element change

For PARAM,TRIA3TYP,DSG3, initial membrane stress now contributes to the local-z translational geometric-stiffness block as well as x/y. The existing local/basic transformation is retained. The previously tested consistent-spin drilling and thermal-gradient load contribution are preserved in this production source. No new selector is needed. Elastic stiffness, drilling coefficient, supports, prestress recovery and shared solver implementation are unchanged by the Kg_zz correction.

The old omission prevented transverse plate buckling; the first reported positive mode was instead an in-plane mode with critical stress around 703.68 ksi for bending and 303.15 ksi for shear. Independent Python/native matrix comparisons confirm the corrected operator. Use sigma_cr=lambda*qmax/t for these benchmarks, not lambda times the maximum recovered element preload stress.

## KNOWN FAIL — retained, not waived

- Problem 2-016c bending, LC2, 64x64 parent panels / four triangles per panel, t=.01 in, six requested modes: default-margin corrected native run fails mode2 residual **1.994985128e-6**, exceeding the unchanged **1e-6** acceptance limit.
- DARPACK4/6 does not resolve bending: mode2 remains approximately 1.995e-6. The original-drilling comparison also fails mode2 (~1.694e-6). No cause beyond the verified element omission is claimed for this residual sensitivity.
- The first bending mode alone matches Python: sigma_cr=.1163632 ksi versus .1165 ksi, MAC~1. This diagnostic is not substituted for a six-mode pass.
- Corrected shear with default DARPACK2 fails mode6 residual 1.956658667e-6. **Use PARAM,DARPACK,4 for this shear benchmark**: all six modes pass, sigma_cr=.04249066 ksi versus .0425 ksi. DARPACK6 also passes.

The native residual rejection stays active. Failed runs remain failures in CSV/F06; no tolerance relaxation, backend change, automatic fallback or silent mode reduction is introduced.

## Verification and limits

Fresh full suite before/after: baseline 71/71 completed; corrected default-margin candidate 69/71, with the two 2-016c failures above. All 183 other extracted measures are identical to printed precision. The separate DARPACK4 shear run yields a qualified 70/71 set; bending remains open. This combines the original full suite and the documented input rerun, not a fresh 71-case rerun.

Python/native elastic matrix difference 1.22e-16; geometric matrix difference 2.67e-14 on the rotated XZ column mesh. Native/Python six shear mode shapes match, MAC~1. Analytic plate convergence, rotated/reflected plate frames, Euler strip, unchanged static K and unchanged in-plane Kg checks pass. Higher column modes may change when the transverse block enables additional modes; only the first critical load is unchanged in the current regression metric.

This correction does not certify arbitrary curved-shell rotational/director geometric terms. Twisted-beam/roof trade-offs of consistent-spin drilling remain documented separately. Thermal-stress recovery remains a separate open audit.
